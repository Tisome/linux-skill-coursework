# 终版复测

以同一份[第八周 ELF 材料](../cases/07-elf.md)喂给 v1 和 v7。技能各自的归档参考文件属于被测试的 Skill，任务和题面相同。

v1 正确解释两个入口，并标出未转储栈内存。它漏掉 `DT_NEEDED` 与 `dlopen` 的对照，也没有把证据落实到具体复查命令。v7 两项都覆盖。参见 [v1](../output/v1/same-elf.md) 和 [v7](../output/v7/same-elf.md)。

再用[第十周阅读题](../cases/transfer-reading.md)复测。v7 能使用“问题—解释”的形式回复并标明证据类型。样例没有测试运行，因此不能凭这次输出判断虚拟化、容器或课堂云机是否运行正常。
