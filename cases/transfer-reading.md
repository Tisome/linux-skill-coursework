# 第十周 · KVM 与 Linux 容器

归档阅读稿引用《庖丁解牛 Linux 操作系统分析》第十、十一章，印刷页 291–340。内容有 KVM、QEMU、地址转换、vCPU、namespace、cgroups 和 OCI。归档说明本次为教材阅读，没有现场运行命令或截图。Linux 容器共享宿主内核；namespace 隔离资源视图，cgroups 用于资源限制和统计。

任务：写一份短预习，解释 KVM/QEMU 分工、容器与虚拟机的区别、namespace 与 cgroups 的区别，并说明阅读范围和证据类型。依据 [课程演进记录](../archive/course-evolution.md) 的第十周。
