# KVM 与 Linux 容器 · 阅读迁移

阅读范围是《庖丁解牛 Linux 操作系统分析》第十、十一章（印刷页 291–340）。本次根据归档阅读材料归纳。

- **KVM 与 QEMU 各做什么？** KVM 在 Linux 内核中提供虚拟化支持。这个组合里，QEMU 负责用户态设备模型与虚拟机的运行组织，通过 KVM 使用硬件虚拟化。
- **容器和虚拟机的区别在哪里？** 虚拟机运行自己的来宾内核。Linux 容器仍使用宿主内核，为进程设置独立的资源视图和约束。
- **namespace 与 cgroups 各隔离什么？** namespace 决定进程看到哪些资源视图。cgroups 用于分组后统计和限制资源用量，例如 CPU 与内存。

材料类型是教材阅读记录。命令运行、镜像启动和内核调试属于另外的实践验证。
