# 第二周 · C 函数调用与栈

课程要求是分析 C 程序生成的 32 位汇编、函数调用中栈的变化和计算机如何工作。左侧题面参考程序为 `g(x)=x+3`，`f(x)=g(x)`，`main` 返回 `f(8)+1`，题目要求学生另改数字。右侧终端先把提示符 `$` 输入命令并报错，重试 `gcc -S -o main.s main.c -m32` 后列出了 `main.s`。截图未展开实际源文件或汇编，也没有调试器记录。

任务：解释命令、参考数值与典型栈帧现象，注明哪些结论需要更多证据。参见[归档原稿和题面截图](../archive/first-preview/original.md)。
